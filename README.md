# Elena Varga Atelier

A design concept for a solo drawing-and-painting school on Tutor LMS (convertible to an academy). Static HTML, CSS and vanilla JS, with no build step.

- `index.html`: home · `about.html` · `courses.html` · `course.html` · `lesson.html` · `style.html` (the design language)
- `assets/site.css`, `assets/site.js`: shared styles and behaviour
- `tools/audit.mjs`: design check (`node tools/audit.mjs --desktop <page>`) · `tools/build-artifact.py`: preview build
- `openspec/`: plans (OpenSpec) · `research/tutorlms/`: Tutor LMS study
